# Lukecho Labs site

Public product, privacy, terms, support, and deletion pages for the future Xai Grok Media distribution channels.

The site contains no protected plugin source, credentials, buyer data, or service tokens. It is a static GitHub Pages project.

## Local preview

```powershell
python -m http.server 8080
```

## Publication

GitHub Pages validates the source and deploys only the explicit public-file allowlist staged in `_site` by the pinned workflow in `.github/workflows/pages.yml`.
