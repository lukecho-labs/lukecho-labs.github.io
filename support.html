Product support

Get help without sharing credentials.

The open-source Lukecho Media Studio plugin is available now. Hosted generation, customer accounts, billing, and paid support are not open.

Install and use the plugin

Start with the installation and verification guide for Codex or Claude Code.

Repository support

For non-sensitive questions or reproducible defects, open an issue in the public plugin repository. Do not include account identifiers or private media.

Security reports

Do not post secrets, webhook payloads, account IDs, private repository names, media files, or signed URLs in an issue. Use GitHub private vulnerability reporting on the public plugin repository.

Account and billing

The current plugin has no Lukecho account, subscription, checkout, or included generation credits. A compatible third-party media tool remains subject to its own permissions, terms, and quota.

Hosted service status

No production hosted service or response-time commitment is advertised. This page will be updated before either is offered.
